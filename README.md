 # Digital Wellbeing – Screen Time Reminder ⏱️

A C-based console application that helps track and manage daily screen usage.  
It calculates totals and averages, highlights longest and shortest sessions, and provides break reminders to reduce fatigue.  
Daily reports are saved to promote digital wellness and better time management.

---

## 🚀 Features
- Track daily screen usage with a single array
- Calculate total and average screen time
- Identify longest and shortest sessions
- Provide break reminders to reduce fatigue
- Save daily reports for long-term tracking

---

## 🛠️ Skills & Technologies
- C Programming (core app logic)
- JavaScript (frontend scripts)
- Python (desktop tracker integration)
- HTML & CSS (UI components)
- React, Node.js (future expansion)
